# learning_programing

平时写的一些算法题解和学习代码，顺手存一下，方便以后翻看和复习。

## 目录说明

```text
learning_programing/
├── ...    # 各类算法题、练习代码
```

目录和文件大多按题目或知识点随手命名，没有严格的规范，以实际内容为准。

## 内容

- 算法题解（LeetCode / 其他平台）
- 学习过程中敲的示例代码
- 一些小练习和实验性代码

## 说明

- 代码以“能跑通、记录思路”为主，不追求工程化
- 部分文件带有注释，部分没有
- 持续更新中

## 环境

语言和工具比较杂，取决于具体文件，常见的有：

- Python / C++ / Java 等
- 一般直接本地运行或在线判题
