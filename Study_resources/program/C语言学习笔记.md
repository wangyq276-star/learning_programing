## 1. C 语言基础回顾

### 1.1 一个最简单的 C 程序

```c
#include <stdio.h>

int main(void)
{
    printf(\"Hello, world!\\n\");
    return 0;
}
```

- `#include <stdio.h>`：引入标准输入输出头文件。
- `int main(void)`：程序入口函数。
- `printf()`：向终端输出内容。
- `\\n`：换行符。
- `return 0;`：通常表示程序正常结束。

### 1.2 常见数据类型

| 类型 | 常见用途 | 示例 |
|---|---|---|
| `char` | 字符或小整数 | `char c = 'A';` |
| `int` | 整数 | `int age = 18;` |
| `float` | 单精度浮点数 | `float x = 3.14f;` |
| `double` | 双精度浮点数 | `double y = 3.14;` |
| `void` | 表示没有具体值或类型 | `void print(void);` |

### 1.3 常见运算符

| 类别 | 运算符 | 含义 |
|---|---|---|
| 算术 | `+ - * / %` | 加、减、乘、除、取余 |
| 比较 | `== != < <= > >=` | 比较大小或相等 |
| 逻辑 | `&& || !` | 与、或、非 |
| 赋值 | `=` | 把右侧的值赋给左侧 |
| 地址 | `&` | 取得对象的地址 |
| 解引用 | `*` | 通过指针访问所指对象 |

**注意：**

```c
x = 5;      // 赋值
x == 5;     // 判断 x 是否等于 5
```

`=` 和 `==` 的用途不同，不能混淆。

整数除法也需要注意：

```c
printf(\"%d\\n\", 5 / 2);  // 输出 2
```

因为两个操作数都是整数，所以结果也是整数。

## 2. 数组与字符串

### 2.1 数组是什么？

数组用于存储一组**类型相同**的数据，元素在内存中连续排列。

```c
int numbers[3] = {10, 20, 30};

printf(\"%d\\n\", numbers[0]); // 10
printf(\"%d\\n\", numbers[1]); // 20
printf(\"%d\\n\", numbers[2]); // 30
```

数组下标从 `0` 开始，因此长度为 `3` 的数组，有效下标是 `0`、`1`、`2`。

### 2.2 字符串是什么？

C 语言没有独立的内置字符串类型。通常使用以 `\\0` 结尾的字符数组表示字符串。

```c
char name[] = \"Alice\";
```

内存中包含：

```text
'A' 'l' 'i' 'c' 'e' '\\0'
```

末尾的 `\\0` 是字符串结束标记，不应遗漏。

### 2.3 常见字符串函数

使用这些函数需要包含：

```c
#include <string.h>
```

| 函数 | 用途 | 注意事项 |
|---|---|---|
| `strlen(s)` | 计算字符串长度，不包含结尾的 `\\0` | 参数必须是有效的、以 `\\0` 结尾的字符串 |
| `strcmp(a, b)` | 比较两个字符串 | 返回 `0` 表示内容相同 |
| `strcpy(dst, src)` | 复制字符串 | 目标空间必须足够大 |
| `strcat(dst, src)` | 把字符串拼接到目标字符串末尾 | 目标空间必须足够大 |

比较字符串时，不要这样写：

```c
if (a == b) {
    // 这不是比较两个字符串的内容
}
```

应该使用：

```c
if (strcmp(a, b) == 0) {
    // 两个字符串内容相同
}
```

## 3. 函数与参数传递

### 3.1 定义函数

```c
int add(int a, int b)
{
    return a + b;
}
```

调用：

```c
int result = add(3, 4); // result 为 7
```

### 3.2 C 语言的参数传递

C 语言的参数是**按值传递**的，也就是说，函数接收到的是实参值的副本。

```c
void change(int x)
{
    x = 100;
}

int main(void)
{
    int a = 10;
    change(a);

    printf(\"%d\\n\", a); // 仍然是 10
    return 0;
}
```

如果希望函数修改调用方的变量，可以传入变量的地址：

```c
void change(int *p)
{
    *p = 100;
}

int main(void)
{
    int a = 10;
    change(&a);

    printf(\"%d\\n\", a); // 100
    return 0;
}
```

这里发生的事情是：

1. `&a` 取得变量 `a` 的地址。
2. 函数参数 `p` 接收这个地址。
3. `*p` 访问地址所指向的变量。
4. 修改 `*p`，实际修改的就是 `a`。

## 4. 结构体 `struct`

### 4.1 结构体的作用

数组只能直接存放同一种类型的数据。结构体可以把不同类型的相关数据组合起来。

例如，一个学生可能有学号、年龄和成绩：

```c
struct Student {
    int id;
    int age;
    double score;
};
```

### 4.2 创建结构体变量

```c
struct Student s = {1001, 18, 92.5};

printf(\"%d\\n\", s.id);
printf(\"%d\\n\", s.age);
printf(\"%.1f\\n\", s.score);
```

使用 `.` 访问结构体变量的成员：

```c
s.id
s.age
s.score
```

### 4.3 通过结构体指针访问成员

```c
struct Student s = {1001, 18, 92.5};
struct Student *p = &s;

printf(\"%d\\n\", p->id);
```

这里：

- `p` 是指向 `struct Student` 的指针。
- `p->id` 访问指针所指结构体的 `id` 成员。
- `p->id` 等价于 `(*p).id`。

括号不能省略成 `*p.id`，因为 `.` 的优先级高于一元 `*`。

## 5. 指针与地址

### 5.1 指针是什么？

**指针是用来保存地址的变量。**

```c
int x = 10;
int *p = &x;
```

可以把它理解为：

```text
变量 x：保存数值 10
指针 p：保存变量 x 的地址
```

### 5.2 `&`：取地址

```c
int x = 10;
int *p = &x;
```

`&x` 表示取得 `x` 的地址，然后把这个地址存入 `p`。

### 5.3 `*`：解引用

```c
int x = 10;
int *p = &x;

printf(\"%d\\n\", *p); // 10
*p = 20;

printf(\"%d\\n\", x);  // 20
```

在表达式中，`*p` 表示访问 `p` 所指向的对象。

因此：

```c
*p = 20;
```

不是把指针 `p` 改成 `20`，而是把 `p` 指向的那个整数改成 `20`。

### 5.4 指针类型

```c
int *p1;
char *p2;
double *p3;
```

指针类型说明了它指向哪种类型的对象。解引用时，编译器会按对应类型解释内存。

### 5.5 空指针与未初始化指针

空指针：

```c
int *p = NULL;
```

`NULL` 表示这个指针当前不指向可用对象。不能直接解引用：

```c
// printf(\"%d\", *p); // 错误：不能解引用空指针
```

未初始化的局部指针也不能直接使用：

```c
int *p;
// *p = 10; // 错误：p 没有被初始化为有效地址
```

**原则：解引用指针之前，必须确认它指向一个有效且仍处于生命周期内的对象。**

## 6. 数组与指针的关系

### 6.1 数组名在表达式中通常会转换为首元素地址

```c
int arr[3] = {10, 20, 30};
int *p = arr;
```

在这里，`arr` 在赋值表达式中会转换为指向首元素 `arr[0]` 的指针，因此 `p` 指向数组第一个元素。

### 6.2 下标访问与解引用

```c
int arr[3] = {10, 20, 30};
int *p = arr;

printf(\"%d\\n\", *p);      // 10
printf(\"%d\\n\", p[0]);    // 10
printf(\"%d\\n\", p[1]);    // 20
printf(\"%d\\n\", *(p + 2));// 30
```

对于指针 `p`：

```c
p[i]
```

等价于：

```c
*(p + i)
```

所以，**指针既可以通过解引用访问元素，也可以使用下标运算符 `[]` 访问元素**，前提是访问范围有效。

### 6.3 数组与指针并不完全相同

虽然数组名在很多表达式中会转换为首元素地址，但数组本身不是普通指针变量。

```c
int arr[3] = {10, 20, 30};
int *p = arr;

p = p + 1; // 合法：让 p 指向下一个元素
// arr = arr + 1; // 不合法：数组名不能这样重新赋值
```

另外，在数组本身仍然可见的地方：

```c
sizeof(arr)
```

得到的是整个数组占用的字节数；而：

```c
sizeof(p)
```

得到的是指针变量本身占用的字节数。二者通常不同。

### 6.4 指针加减

假设：

```c
int arr[3] = {10, 20, 30};
int *p = arr;
```

那么：

- `p` 指向 `arr[0]`。
- `p + 1` 指向 `arr[1]`。
- `p + 2` 指向 `arr[2]`。

指针加 `1` 会移动一个所指类型元素的距离，不是固定移动一个字节。指针运算只能在同一个数组对象内或其尾后位置等标准允许的范围内进行；尾后位置不能解引用。

## 7. `const` 关键字

`const` 可以限制通过某个变量名或指针进行修改的操作。

### 7.1 普通常量对象

```c
const int x = 10;
// x = 20; // 错误：不能通过 x 修改它
```

### 7.2 指向常量的指针

```c
int x = 10;
const int *p = &x;

// *p = 20; // 错误：不能通过 p 修改 x
p = NULL;   // 可以修改 p 自身
```

`const int *p` 的重点是：**不能通过 `p` 修改它所指向的整数**。

### 7.3 常量指针

```c
int x = 10;
int y = 20;

int *const p = &x;

*p = 30;  // 可以：修改 x
// p = &y; // 错误：不能让 p 改为指向 y
```

`int *const p` 的重点是：**指针本身不能改为指向其他地址**。

### 7.4 指向常量的常量指针

```c
int x = 10;
const int *const p = &x;
```

通过 `p` 不能修改所指整数，`p` 本身也不能改为指向其他地址。

### 7.5 `const` 的常见用途

函数只需要读取数组内容时，可以写成：

```c
void print_values(const int *arr, int count)
{
    for (int i = 0; i < count; i++) {
        printf(\"%d\\n\", arr[i]);
    }
}
```

这样可以表达函数不会通过 `arr` 修改数组元素，也有助于防止误操作。

## 8. 动态内存管理

### 8.1 为什么需要动态内存？

有时程序运行时才知道需要保存多少数据。此时可以使用动态内存分配函数。

相关函数位于：

```c
#include <stdlib.h>
```

### 8.2 `malloc`

`malloc` 根据指定的字节数申请内存，成功时返回指针，失败时返回 `NULL`。

```c
int *p = malloc(10 * sizeof *p);

if (p == NULL) {
    // 申请失败，进行错误处理
} else {
    // 可以使用 p[0] 到 p[9]

    free(p);
    p = NULL;
}
```

这里申请了足以存放 `10` 个 `int` 元素的空间。

说明：

- `sizeof *p` 表示 `p` 所指类型的大小。
- `malloc` 不会自动把分配到的内存初始化为 `0`。
- 申请成功后，使用范围不能超出申请的空间。

### 8.3 `free`

不再需要动态申请的内存时，应调用 `free` 释放：

```c
int *p = malloc(sizeof *p);

if (p != NULL) {
    *p = 42;
    printf(\"%d\\n\", *p);

    free(p);
    p = NULL;
}
```

### 8.4 常见内存错误

| 错误 | 说明 |
|---|---|
| 内存泄漏 | 申请的内存不再需要，却没有释放 |
| 空指针解引用 | 对 `NULL` 指针进行 `*p` 等操作 |
| 越界访问 | 访问申请空间之外的内存 |
| 释放后使用 | `free(p)` 后仍通过旧指针访问内存 |
| 重复释放 | 同一块内存被重复 `free` |
| 使用未初始化内存 | 读取尚未正确赋值的动态内存内容 |

把指针设为 `NULL` 可以降低某些误用风险，但不能修复程序中所有指向同一内存的其他指针。

## 9. 单向链表

### 9.1 链表是什么？

数组的元素通常连续存放；链表则由多个节点组成，每个节点通过指针连接到下一个节点。

一个简单的单向链表可以表示为：

```text
head
 |
 v
[10 | next] -> [20 | next] -> [30 | NULL]
```

每个节点通常包含：

1. 数据字段。
2. 指向下一个节点的指针。

### 9.2 定义节点

```c
struct Node {
    int data;
    struct Node *next;
};
```

`next` 的类型是 `struct Node *`，也就是指向另一个节点的指针。

链表头指针：

```c
struct Node *head = NULL;
```

`head == NULL` 表示当前链表为空。

### 9.3 创建一个节点

```c
struct Node *node = malloc(sizeof *node);

if (node != NULL) {
    node->data = 10;
    node->next = NULL;
}
```

这里分别给数据字段和指针字段赋值。创建节点后，应确保节点最终被接入链表，或者在不需要时释放它。

### 9.4 遍历链表

```c
for (struct Node *cur = head;
     cur != NULL;
     cur = cur->next) {
    printf(\"%d\\n\", cur->data);
}
```

理解这个循环：

1. `cur = head`：从第一个节点开始。
2. `cur != NULL`：只要还存在节点就继续。
3. `cur = cur->next`：移动到下一个节点。

这里使用 `cur` 作为遍历指针，而不是直接不断修改 `head`，因为需要保留链表入口。

### 9.5 头部插入节点

```c
struct Node *node = malloc(sizeof *node);

if (node != NULL) {
    node->data = value;
    node->next = head;
    head = node;
}
```

执行顺序很重要：

```text
原链表：head -> A -> B -> NULL

1. node->next = head
   node -> A -> B -> NULL
   head -> A -> B -> NULL

2. head = node
   head -> node -> A -> B -> NULL
```

如果先把 `head` 改成新节点，却没有保存原链表入口，就可能丢失原有链表。

### 9.6 查找节点

```c
struct Node *find_node(struct Node *head, int target)
{
    struct Node *cur = head;

    while (cur != NULL) {
        if (cur->data == target) {
            return cur;
        }

        cur = cur->next;
    }

    return NULL;
}
```

找到时返回节点指针；没有找到时返回 `NULL`。

### 9.7 为什么有时需要 `struct Node **head`？

假设函数需要改变调用方的头指针，例如在链表头部插入或删除头节点。

如果只传入：

```c
void func(struct Node *head);
```

函数得到的是头指针值的副本。直接修改函数内的 `head`，不会改变调用方的 `head`。

一种解决办法是传入头指针的地址：

```c
void push_front(struct Node **head, int value)
{
    struct Node *node = malloc(sizeof *node);

    if (node == NULL) {
        return;
    }

    node->data = value;
    node->next = *head;
    *head = node;
}
```

调用：

```c
struct Node *head = NULL;
push_front(&head, 42);
```

这里：

- `head` 的类型是 `struct Node *`。
- `&head` 的类型是 `struct Node **`。
- `*head` 在函数中表示调用方的头指针。
- `*head = node` 会更新调用方的 `head`。

另一种设计是让函数返回更新后的头指针：

```c
struct Node *push_front(struct Node *head, int value);
```

调用时：

```c
head = push_front(head, 42);
```

两种方式都可以，关键是调用方必须获得更新后的头指针。

### 9.8 删除节点时要考虑什么？

删除节点时，通常需要：

1. 找到目标节点。
2. 找到它的前一个节点（如果目标不是头节点）。
3. 调整链路，让链表跳过目标节点。
4. 使用 `free` 释放目标节点。

必须考虑这些情况：

- 链表为空。
- 删除头节点。
- 删除中间节点。
- 删除尾节点。
- 目标值不存在。
- 链表只有一个节点。

释放节点前要先正确调整链路，否则可能丢失后续节点的地址。

### 9.9 链表与数组的区别

| 比较项 | 数组 | 链表 |
|---|---|---|
| 内存组织 | 元素连续存放 | 节点可分散存放 |
| 按下标访问 | 通常为 O(1) | 通常为 O(n) |
| 插入/删除中间元素 | 可能需要移动后续元素 | 已找到位置后可通过改指针完成 |
| 额外空间 | 通常不需要每个元素保存链接指针 | 节点需要保存指针 |
| 内存管理 | 普通局部数组常由作用域管理 | 动态节点通常需要手动释放 |

## 10. 键值对与常见数据结构

### 10.1 什么是键值对？

键值对是一种把 `key`（键）映射到 `value`（值）的数据组织方式。

例如：

```text
学号 1001 -> 成绩 92
学号 1002 -> 成绩 85
学号 1003 -> 成绩 97
```

如果熟悉 Python，可以把它理解成类似字典 `dict` 的概念。

### 10.2 C 语言没有内置的通用 `map`

C 标准库没有直接等同于 C++ `std::map` 的通用容器。因此通常需要：

- 自己定义结构体和存储逻辑；
- 自己实现数组、链表、哈希表或树；
- 或使用第三方数据结构库。

### 10.3 方案一：结构体数组

```c
struct Entry {
    int key;
    int value;
};

struct Entry entries[100] = {
    {1001, 92},
    {1002, 85},
    {1003, 97}
};
```

每个数组元素就是一组键值对。

优点：

- 结构简单。
- 容易理解和实现。
- 数据连续存放，遍历方便。

缺点：

- 查找通常需要从头扫描。
- 固定数组容量有限；动态数组需要另外实现扩容。
- 如果要求 key 唯一，需要自己处理重复键。

### 10.4 方案二：用链表保存键值对

可以把节点定义为：

```c
struct EntryNode {
    int key;
    int value;
    struct EntryNode *next;
};
```

每个节点存储一组键值对。

优点：

- 可以动态增加和删除节点。
- 不必预先确定固定容量。

缺点：

- 查找通常需要线性遍历。
- 每个节点需要额外保存 `next` 指针。
- 需要正确处理动态内存。

### 10.5 方案三：哈希表

哈希表通过哈希函数把 key 映射到数组中的某个位置。

```text
key -> 哈希函数 -> 数组下标 -> 找到对应数据
```

理想情况下，查找和插入的平均时间复杂度可以接近 `O(1)`。

但是，不同的 key 可能得到相同下标，这叫作**哈希冲突**。

一种常见的处理方法是拉链法：

```text
桶 0 -> NULL
桶 1 -> [key=11] -> [key=21] -> NULL
桶 2 -> [key=12] -> NULL
桶 3 -> NULL
```

同一个桶中的多个节点通过链表连接。

实现哈希表时需要考虑：

- 哈希函数如何计算。
- 桶数组有多大。
- 哈希冲突如何处理。
- 相同 key 再次插入时，是覆盖旧值还是拒绝插入。
- 删除节点时如何维护链路。
- 何时释放节点。
- 负载因子过高时是否扩容。

### 10.6 方案四：二叉搜索树

二叉搜索树通常按 key 的大小关系组织节点：

- 比当前节点小的 key 放在左子树。
- 比当前节点大的 key 放在右子树。

普通二叉搜索树可能因为插入顺序不理想而退化，操作复杂度可能达到 `O(n)`。平衡搜索树能提供更稳定的对数级操作，但实现复杂度更高。

### 10.7 应该选择哪种方式？

| 需求 | 可考虑的方案 |
|---|---|
| 数据少，逻辑简单 | 结构体数组 |
| 需要动态插入和删除，规模不大 | 链表 |
| 需要频繁根据 key 查找 | 哈希表 |
| 需要按 key 排序、顺序遍历 | 搜索树或排序数组 |

### 10.8 如果 key 是字符串

字符串键值对需要额外注意：

```c
strcmp(a, b) == 0
```

用于判断两个字符串的内容是否相同。

不能用 `a == b` 来代替字符串内容比较。

如果数据结构需要长期保存传入的字符串 key，通常要复制字符串，并在删除对应记录时释放复制的内存。不能随意保存一个生命周期很短的临时缓冲区地址。

## 11. 泛型、`<>` 与 C/C++ 的区别

### 11.1 泛型是什么？

泛型的核心思想是：**让同一套代码能够处理多种数据类型，减少重复代码。**

例如，希望容器既能保存整数，也能保存浮点数或字符串，就会涉及泛型设计。

### 11.2 C++ 模板示例

```cpp
std::map<int, int> scores;
std::vector<int> numbers;
```

这里的 `std::map<int, int>` 和 `std::vector<int>` 使用了 C++ 模板。

它们不是 C 语言语法，不能直接放进普通的 C 源文件中编译。

### 11.3 C 语言中尖括号 `<>` 的常见含义

```c
#include <stdio.h>
```

这里的尖括号表示以标准头文件的方式查找 `stdio.h`，与泛型无关。

因此，看到 `<>` 时，要根据上下文判断它的含义。

### 11.4 C 语言如何实现一定程度的通用性？

常见方式包括：

- **`void *`**：保存不同对象的地址，但需要自行管理类型、大小和生命周期。
- **宏**：通过预处理器生成重复代码，但要注意类型安全和调试问题。
- **分别编写不同类型的函数**：简单直接，但可能出现重复代码。
- **第三方容器库**：使用已有的通用数据结构实现。

`void *` 不会自动记录所指对象的实际类型。使用时必须保证转换方式、对象大小、对齐要求和生命周期都正确。

### 11.5 C 语言与 C++ 的重要区别

| 特性 | C | C++ |
|---|---|---|
| 结构体 | `struct` | `struct`，并支持更多面向对象能力 |
| 引用类型 | 没有 C++ 引用语法 | 支持引用，如 `int &ref = x;` |
| 模板 | 没有 C++ 模板 | 支持模板，如 `std::vector<int>` |
| 标准键值容器 | 没有内置通用 `map` | 标准库提供 `std::map`、`std::unordered_map` |
| 动态内存 | 常用 `malloc` / `free` | 可用 `new` / `delete`，也常使用智能指针和标准容器 |

## 12. 常见错误清单

写程序时可以逐项检查：

- [ ] 数组下标是否越界？
- [ ] 字符串是否有足够空间保存结尾的 `\\0`？
- [ ] 是否混淆了 `=` 和 `==`？
- [ ] 指针是否已初始化？
- [ ] 是否可能对 `NULL` 指针解引用？
- [ ] 指针指向的对象是否仍然有效？
- [ ] `malloc` 是否检查了返回值？
- [ ] 不再使用的动态内存是否正确 `free`？
- [ ] 是否在 `free` 后继续使用旧指针？
- [ ] 是否重复释放同一块内存？
- [ ] 链表插入时是否正确保存原有链路？
- [ ] 链表删除时是否处理了空链表和头节点？
- [ ] 链表节点是否最终都能被释放？
- [ ] 是否使用 `strcmp` 比较字符串内容？
- [ ] 是否把 C++ 的引用或模板语法误写进 C 程序？

## 13. 下一步学习路线

按照目前涉及的内容，可以按下面的顺序继续学习：

1. **巩固指针与数组**：练习函数参数、数组遍历、字符串处理。
2. **完整实现单向链表**：编写创建、头插、尾插、查找、删除、遍历和释放全部节点的函数。
3. **实现简单键值对容器**：先实现 `int -> int`，再尝试字符串 key。
4. **实现哈希表**：理解哈希函数、冲突处理和拉链法。
5. **学习文件读写**：使用 `fopen`、`fgets`、`fprintf`、`fclose` 等函数。
6. **学习多文件编译**：理解头文件、源文件、声明与定义。
7. **学习调试与编译警告**：让编译器帮助发现潜在错误。

编译时可以使用 GCC 的常见警告选项：

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o main
```

其中：

- `-std=c11`：使用 C11 标准。
- `-Wall -Wextra -Wpedantic`：开启一组常见警告。
- `-o main`：指定生成的可执行文件名。

## 总结

目前这份笔记的重点是：理解数据如何存储、地址如何使用，以及如何用结构体、指针和动态内存组织数据。

尤其要熟练掌握以下几组关系：

- `&x`：取得变量 `x` 的地址。
- `*p`：访问指针 `p` 指向的对象。
- `p->member`：通过结构体指针访问成员。
- `p[i]` 与 `*(p + i)`：等价的指针下标访问形式。
- `struct Node **head`：允许函数通过二级指针修改调用方的头指针。
- `malloc` 与 `free`：动态内存的申请和释放需要配套管理。
- 键值对：是一种数据组织方式，可以用数组、链表、哈希表或树来实现。
- C++ 模板与引用：属于 C++ 特性，不是 C 语言语法。
